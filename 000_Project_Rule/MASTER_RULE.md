# MASTER_RULE

Status: LOCK

Version: v1.0

## 最上位ゴール

comic-Flameは、AIを漫画制作工程の一員として扱い、継続的に漫画制作を行える環境を構築する。

目的は単なる画像生成ではない。

物語理解、キャラクター維持、漫画演出判断、ネーム制作、コマ割り、作画準備を一貫した工程として管理する。

## 判断優先順位

1.  プロジェクトの最上位目的
2.  LOCK済み聖典
3.  工程別ルール
4.  個別資料
5.  AI判断

上位項目と矛盾する判断は禁止する。

## 禁止事項

-   聖典・LOCK事項を確認せず作業開始しない
-   既存設定を勝手に変更しない
-   要約によって重要情報を削除しない
-   目的を変更する改善を行わない
-   推測を確定事項として扱わない

LOCK: 本ファイルをcomic-Flame全体の最上位ルールとする。
