漫画制作に使用するB5縦漫画ネーム用コンテ枠の生成基準。

---

# 1. 基本ページ仕様

- 用紙サイズ：B5縦
- 1ページ単位で作成
- 漫画原稿用のコマ枠のみ作成
- 絵、人物、背景、セリフ、吹き出しは入れない
- 後工程で作画を入れるための設計図として扱う

---

# 2. 漫画形式

## 右綴じ漫画

日本式漫画として作成する。

読み順：

1. 右上
2. 左上
3. 右下
4. 左下
5. 次の段へ

---

# 3. コマ配置ルール

## 横並びの場合

読む方向は、

右 → 左

とする。

横方向に2つ以上のコマを配置する場合、
必ず右側のコマを若い番号にする。

左側のコマは次の番号になる。

例：

```
┌──────┬──────┐
│  2   │  1   │
│ 左   │ 右   │
└──────┴──────┘
```

読み順：
1 → 2

禁止：

```
┌──────┬──────┐
│  1   │  2   │
│ 左   │ 右   │
└──────┴──────┘
```

これは左綴じ漫画の配置になるため禁止。

---

## 縦方向の場合

読む方向は、

上 → 下

とする。

上段を読んだ後、下段へ進む。

---

# 4. コマ番号

- コマ番号は実際の読み順で表示する
- 番号と読む順番を一致させる
- コマ番号はコマ内右上に配置する

---

# 5. コマ数基準

基本：

- 通常ページ：3〜5コマ
- 会話ページ：4〜6コマ
- 印象的な演出ページ：1〜3大コマ

禁止：

- B5縦で過密な8コマ構成
- 全ページ同じテンプレート
- 情報を全てコマ化する構成

---

# 6. 演出基準

コマ割りはページごとの役割を優先する。

必ず考慮する：

- このページで何を伝えるか
- 読者に何を感じさせるか
- 見せ場となるコマはどこか
- 次ページへの引き

---

# 7. 禁止事項

- 左綴じ漫画の読み順にしない
- 横並びを左→右にしない
- コマ番号だけ右綴じにして配置を間違えない
- 全ページ均等割りにしない
- B5で小さいコマを大量配置しない

---

# 8. 作成チェック

完成前に確認する。

□ B5縦か
□ 右綴じか
□ 右上開始か
□ 横並びは右→左か
□ 縦方向は上→下か
□ 番号順に読めるか
□ 横並びコマの若い番号は必ず右側にあるか
□ 左右反転した読み順になっていないか
□ 演出目的に合っているか
