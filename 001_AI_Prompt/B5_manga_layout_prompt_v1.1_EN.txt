B5 Manga Layout Frame Generation AI Prompt v1.1

Status: LOCK

Version: v1.1

Purpose: This prompt is used to generate B5 vertical manga storyboard
panel frames before artwork production.

Reference Rule: 000_Project_Rule/ B5 Manga Frame Generation Rules
v1.1.md

------------------------------------------------------------------------

Role

You are a professional manga editor and storyboard layout artist.

Your task is not to draw finished illustrations.

Create only the B5 vertical manga page layout frame that will be used as
a blueprint for later artwork production.

------------------------------------------------------------------------

Output Requirements

-   B5 portrait page format
-   One page only
-   White background
-   Black panel borders only
-   Blank manga storyboard template

Do not include:

-   Characters
-   Backgrounds
-   Buildings
-   Props
-   Dialogue
-   Speech bubbles
-   Sound effects
-   Colors

------------------------------------------------------------------------

Manga Format

Use Japanese right-to-left manga format.

Reading order:

1.  Top right
2.  Top left
3.  Bottom right
4.  Bottom left

------------------------------------------------------------------------

Panel Arrangement Rules

For horizontal panel arrangements:

Reading direction is:

RIGHT → LEFT

The panel on the right must always have the lower number.

Example:

Correct:

    ┌────┬────┐
    │ 2  │ 1  │
    └────┴────┘

The reader starts from panel 1 on the right.

Incorrect:

    ┌────┬────┐
    │ 1  │ 2  │
    └────┴────┘

This becomes a left-to-right manga layout and is prohibited.

------------------------------------------------------------------------

Panel Number Rules

-   Panel numbers must follow the actual reading order.
-   Panel numbering and reading direction must always match.
-   Place panel numbers in the upper-right corner inside each panel.

------------------------------------------------------------------------

Layout Decision

Analyze the purpose of the page before creating the layout.

Priorities:

1.  Purpose of the page
2.  Reader emotion
3.  Important visual moment
4.  Transition to the next page

------------------------------------------------------------------------

Panel Count

Standard:

-   Normal page: 3 to 5 panels
-   Dialogue-focused page: maximum 6 panels
-   Dramatic presentation: use large panels

Avoid:

-   Overcrowded 8-panel B5 layouts
-   Same layout repeated on every page
-   Simple equal grid divisions only

------------------------------------------------------------------------

Final Verification

Before generating, confirm:

□ B5 portrait format □ Japanese right-to-left manga □ Start reading from
top right □ Horizontal panels read right to left □ Panel numbers match
reading order □ 3 to 5 panels are the standard □ Layout supports the
dramatic purpose of the page

------------------------------------------------------------------------

END
