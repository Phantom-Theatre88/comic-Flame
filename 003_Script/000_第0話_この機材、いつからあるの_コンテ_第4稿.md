# P1　仕込み前日の劇場倉庫

- **目的**：場所と作業の全体像を一度で示す。

- **人物**：灯堂さんは仕込み図とボードを確認。あかりはケースの列を見ながら数えている。
- **後入れ文字**：なし。
- **注意**：舞台袖・舞台上に見える幕、舞台機構、客席を描かない。古い木箱は倉庫の片隅に背景物として置くが、まだ強調しない。
