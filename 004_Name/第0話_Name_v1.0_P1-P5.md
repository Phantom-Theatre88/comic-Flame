# P1　仕込み前日の劇場倉庫

## ページ目的

劇場倉庫の日常、翌日の仕込み準備、二人の役割、台車が向かう先を成立させる。

## 読者体験

静かな現場作業から始まり、舞台スタッフの日常へ読者を入れる。

## コマ構成

### 1コマ目

位置： 上段全面

サイズ： 横長大コマ

構図： 劇場倉庫内部から積み込み口を見る広角。
照明灯具棚、ケース、台車、積み込み口を見せる。

演出： 場所説明を一度で成立させる。

------------------------------------------------------------------------

### 2コマ目

位置： 中段右

サイズ： 中コマ

構図： 灯堂さんが仕込み図とボードを確認する。

演出： ベテランが黙々と準備している姿を見せる。

------------------------------------------------------------------------

### 3コマ目

位置： 中段左

サイズ： 中コマ

構図： あかりがケースを確認している。

演出： 新人だが現場作業を担当していることを示す。

------------------------------------------------------------------------

### 4コマ目

位置： 下段右

サイズ： 小〜中コマ

構図： 灯堂さんが次のケースを示す。

台詞： 灯堂さん「あかり、次はそのケースを台車に載せといて......」

------------------------------------------------------------------------

### 5コマ目

位置： 下段中央

サイズ： 小コマ

構図： あかりがケースへ向かう。

台詞： あかり「はい！」

------------------------------------------------------------------------

### 6コマ目

位置： 最下段

サイズ： 横長コマ

構図： ケースを台車へ載せ終える瞬間。

演出： P2の台車移動へつながる方向を作る。

------------------------------------------------------------------------

# P2　明日の現場

## ページ目的

作業を続けながら会話へ入り、会場名「パルテノン多摩」を提示する。

## 読者体験

日常会話の中に、物語の入口となる違和感を置く。

## コマ構成

### 1コマ目

位置： 上段全面

サイズ： 横長大コマ

構図： あかりが台車を押しながら灯堂さんへ声をかける。

台詞： あかり「灯堂せんぱい......」

演出： 身体の動きと会話を同時に見せる。

------------------------------------------------------------------------

### 2コマ目

位置： 中段右

サイズ： 小コマ

構図： 灯堂さんは作業を続ける。

台詞： 灯堂さん「......」

------------------------------------------------------------------------

### 3コマ目

位置： 中段左

サイズ： 中コマ

構図： あかりが質問する。

台詞： あかり「灯堂さん！明日の現場ってどこですか？」

------------------------------------------------------------------------

### 4〜8コマ目

演出： 会話の間を作りながら、 「パルテノン多摩」
という言葉への違和感を提示する。

ページ終端： P3の疑問へつなげる。

------------------------------------------------------------------------

# P3　パルテノンって何だろう

## ページ目的

あかりの疑問を深め、古い電球の異変を読者だけに見せる。

## 読者体験

日常の中に小さな違和感が生まれる。

## コマ構成

-   会話で「パルテノン」という言葉への疑問を展開。
-   最後に古い木箱と大型電球を見せる。
-   電球の明滅は説明しない。

ページ終端： 次ページの発光へつなげる。

------------------------------------------------------------------------

# P4　疑問に反応する光

## ページ目的

木箱の異変を二人にも気付かせる。

## 読者体験

静かな倉庫の日常が変化する瞬間を見る。

## コマ構成

-   前半は会話。
-   後半で木箱から光が漏れる。
-   発光は演出の中心として扱う。

ページ終端： ルーメ登場直前で止める。

------------------------------------------------------------------------

# P5　電球がしゃべった

## ページ目的

ルーメを初登場させ、あかりの混乱と灯堂さんの落ち着きを対比する。

## 読者体験

読者もあかりと同じタイミングで異常を体験する。

## コマ構成

### 1コマ目

大コマ。

構図： 古い木箱の光からルーメが浮かび上がる。

演出： 初登場の印象を優先する。

------------------------------------------------------------------------

### 2〜5コマ目

構図： あかりの混乱、 ルーメへの反応、 灯堂さんの落ち着いた対応。

演出： 3人の関係性を成立させる。

ページ終端： 灯堂さんがルーメを知っていることを予感させる。
