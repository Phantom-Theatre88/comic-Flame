# Name_Rule_v1.1

Status:
LOCK

Version:
v1.1

Purpose:
003_Scriptおよび第0話コンテ等の制作資料を、
漫画制作工程で使用可能なネーム資料として整理・管理する。

004_Nameは単なる要約・変換ではない。

元資料を基準として、
漫画として成立させるための編集判断を記録する工程である。

---

# 1. 004_Nameの役割

004_Nameは以下を行う。

- 元コンテの内容確認
- ページ単位の漫画設計整理
- コマ割り確認
- 演出意図確認
- 後工程（コマ枠生成・作画）への引き渡し

目的は情報削減ではない。

必要な情報を保持したまま、
制作工程で利用可能な形へ整理する。

---

# 2. 元コンテとの関係

003_Scriptに含まれるコンテ資料は、
ネーム制作の基準資料とする。

004_Nameでは元資料を上書きしない。

元案と編集後の判断を分けて管理する。

---

# 3. 情報の分類

## A. 基本的に変更しない情報

- ページ目的
- 読者体験
- 感情の流れ
- 物語上の役割
- キャラクターの行動理由
- 必要な台詞・情報

---

## B. 編集判断対象

- コマ数
- コマサイズ
- コマ配置
- 大コマ・小コマの使用
- ページ内リズム
- 視線誘導

これらはB5漫画として成立することを優先する。

---

# 4. コマ割り確認ルール

元コンテのコマ割りは、
そのまま採用する前に確認する。

確認項目：

□ B5縦漫画として過密ではないか

□ コマ数が演出目的に対して適切か

□ 同じコマ割りが連続していないか

□ 大きく見せるべき場面が埋もれていないか

□ 読者の視線誘導が成立しているか

---

# 5. コマ割り変更について

コマ割りを変更する場合、
作品目的を維持する。

変更理由を必ず記録する。

例：

変更前：
8コマ

変更後：
5コマ

理由：
B5縦では情報密度が高く、
重要な場面の余白と視認性を確保するため。

---

# 6. 禁止事項

- 元資料を確認せずネーム化する
- 要約によって演出情報を削除する
- コマ数だけを目的に固定する
- コマ数だけを理由なく変更する
- ページ目的を変える
- キャラクター設定を変更する

---
